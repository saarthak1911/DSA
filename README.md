## 🧭 How This Repo Is Organized

Each topic folder follows the same pattern:
- **README.md** — level-wise roadmap of problems covered for that topic.
- **LevelX_*.java** — one file per level, containing all problems for that level.

This keeps every topic self-contained and easy to navigate, while this main README acts as the entry point and index for the whole repo.

## ⚙️ How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/saarthak1911/Java-Collections-Framework.git
   ```
2. Navigate into any topic folder:
   ```bash
   cd ArrayList
   ```
3. Compile and run any level file:
   ```bash
   javac Level1_Basics.java
   java Level1_Basics
   ```
