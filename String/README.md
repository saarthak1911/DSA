# Java String Practice 🚀

A structured, level-wise collection of **Java String programs** to master String manipulation — from basic character operations to advanced interview and LeetCode-level problems. This is part of my ongoing **Java DSA & Collections Framework practice series**.

Each level focuses on a specific set of String concepts, progressing from fundamentals to advanced problem-solving.

# ⚙️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/saarthak1911/String-Practice.git
```

### 2. Navigate into the folder

```bash
cd String-Practice
```

### 3. Compile any level

```bash
javac Level1_Basics.java
```

### 4. Run the program

```bash
java Level1_Basics
```
